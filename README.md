# Анализ банковских транзакций

Этот проект — демонстрационное CLI-приложение на Python для анализа банковских транзакций, полученных из локального Excel-файла. Программа позволяет пользователю загружать операции, формировать отчёты, сохранять их в формате JSON и проводить базовую аналитику расходов.

---

## Реализованный функционал

### Веб-страницы (отображение на стороне клиента)

- **Главная** — основная страница с общим отчётом по транзакциям  
- **События** — *(не реализована, опционально)*

### Сервисы

- **Выгодные категории повышенного кешбэка** — анализ и подсчёт выгодных категорий для кешбэка за выбранный период  
- **Инвесткопилка** — формирование стратегии накоплений с порогами округления (10, 50, 100)  
- **Простой поиск** — поиск транзакций по тексту  
- **Поиск по телефонным номерам** — выделение и поиск номеров телефонов в операциях  
- **Поиск переводов физическим лицам** — фильтрация переводов физическим лицам  

### Отчёты

- **Траты по категории** — расходы по выбранной категории за период  
- **Траты по дням недели** — анализ средних трат по каждому дню недели  
- **Траты в рабочий/выходной день** — анализ расходов в рабочие и выходные дни  

---

## Возможности

- Загрузка транзакций из файла `operations.xlsx` 
- Фильтрация операций по дате, категории и статусу  
- Генерация отчётов с сохранением в JSON  
- Логирование действий и ошибок в файл `logs/reports.log`

## Структура проекта

```bash
├── data/
│   └── operations.xlsx         # Файл с банковскими транзакциями
├── reports/                    # Папка для сохранённых JSON-отчётов
├── logs/
│   └── reports.log             # Файл логирования
├── src/
│   ├── main.py                 # Точка входа в приложение
│   ├── utils.py                # Загрузка и обработка транзакций
│   ├── reports.py              # Функции генерации отчётов
│   ├── views.py                # Интерфейс отчётов для пользователя
│   └── services.py             # Бизнес-логика (анализ)
├── tests/                      # Тесты для всех модулей
├── user_settings.json          # Пользовательские настройки
├── pyproject.toml              # Конфигурация Poetry и зависимости
├── README.md                   # Описание проекта
```

---

## Запуск

1. Установите зависимости через Poetry:

```bash
poetry install
```

2. Запустите приложение:

```bash
poetry run python src/main.py
```
